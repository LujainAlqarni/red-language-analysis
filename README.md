## 📖 About the Project

This repository contains an academic research project about the **RED Programming Language**, a modern programming language designed with the ambitious goal of being a **full-stack programming language**.

The project explores the RED language from both theoretical and practical perspectives, covering its history, implementation, syntax, programming concepts, evaluation criteria, variable types, arrays, scoping, and a practical program written in RED.

The purpose of this project is to provide a comprehensive understanding of RED and its programming concepts as part of a **Programming Languages** course.



## 🔴 What is RED?

**RED** is a cross-platform programming language inspired by the **REBOL** programming language.

It was designed to combine simplicity and expressive power while supporting different programming paradigms and development levels.

One of the main ambitions of RED is to provide a unified language that can be used for tasks ranging from **high-level application development** to **low-level system programming**.

RED consists of two main components:

* **Red** – the high-level programming language.
* **Red/System** – the lower-level language used for system-level programming and building the RED runtime and libraries.

The project examines formal grammar and syntax rules used to describe RED programs, including:

* Expressions.
* Evaluation order.
* Selection statements.
* Loops.

### 4. Language Evaluation

RED is evaluated according to major programming-language evaluation criteria:

* **Readability**
* **Writability**
* **Reliability**

The research also discusses factors such as:

* Simplicity.
* Orthogonality.
* Data types.
* Syntax design.

### 5. Variables

The project explores RED's variable concepts, including:

* Abstract memory cells.
* Variable attributes.
* Primitive data types.
* User-defined data types.

### 6. Array Types

An overview of array types and how they are represented and used in RED.

### 7. Scoping

The research discusses different approaches to variable scope, including:

* Static (Lexical) Scoping.
* Dynamic Scoping.
* Global Context.
* Function Context.
* Namespaces.
